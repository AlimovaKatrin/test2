# Start Here

1. Check out `main`.
2. Run the application with `npm ci && npm run dev`.
3. Start a 60-minute timer.
4. Open `interview/VOICE_MODE_PROMPT.md` from the `interviewer-kit` branch in a separate ChatGPT conversation.
5. Do not inspect the `solution` branch.
6. Complete the interview in English.
7. Inspect `solution` only after the attempt.

The voice-mode prompt is material for a later practice session; repository generation does not execute it.
