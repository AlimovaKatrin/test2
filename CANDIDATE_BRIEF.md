# Candidate Brief — Account Switcher and Race Condition

React and TypeScript mock interview covering parameterised requests, effect cleanup, cancellation, stale responses, and race-condition testing.

## Business goal

Build the smallest accessible, understandable implementation of Stage 1 within the existing starter. The API is local and deterministic.

## Stage 1 only

- Load the available accounts.
- Display an accessible account selector.
- Load transactions for the selected account.
- Display the selected account’s transactions.

## Evidence expected

- Explain your plan in English.
- Confirm the preview result; do not assume code works.
- Run `npm run check` before finishing.
- Prefer one meaningful behavioural test over low-value implementation assertions.
