# Scorecard

## Primary score (0–12)

### Code Quality — 0–4
0 core does not work; 1 partial/fragile; 2 happy path understandable; 3 correct types/boundaries/composition; 4 simple, correct, maintainable, adaptable.

### Testing — 0–4
0 none; 1 static/detail-only; 2 useful success test; 3 meaningful async behavioural coverage; 4 strong boundary coverage including relevant failure/interaction.

### Resilience and UX — 0–4
0 broken/permanent loading; 1 loading+success only; 2 loading/error/empty/success; 3 contextual recovery and invalid-action prevention; 4 relevant stale/partial/duplicate edge cases handled.

**Maximum:** 12  
**Target:** 9/12

## Diagnostic score (0–2 each)

- Functionality
- JavaScript and TypeScript
- React and state
- Networking
- Testing
- Communication and time management

Record direct evidence for every non-zero score.
